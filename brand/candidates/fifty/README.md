# The Fifty (2026-09-11)

Fifty explorations the owner asked for — *"50 more examples, some coin based and
some unique… CS with a club through it like Sugarloaf… CS in a recognizable
golf shape like Fried Egg… some with topo… think outside the box."*

`fifty.svg` holds all fifty as `<g id="m01">…<g id="m50">` on a 96 grid, laid out
10 × 5. Families: **A** coins 01–10 · **B** a club through the letters 11–18 ·
**C** CS in a golf shape 19–28 · **D** topo 29–36 · **E** the season, the crew,
the record 37–44 · **F** outside the box 45–50.

Champagne on the ceremony ground throughout, so the drawings compete and the
colour doesn't; the metal is a separate decision. The pitch page with names and
the sentence for each is in the session artifacts ("The Fifty").
