route to 9, scoped against the real code by six parallel passes that read the

## Three things the planning pass found

Scoping against the code rather than the findings list changed three items.

### 1 · Home has been showing the wrong number — and sometimes the wrong band
Graded "the allowance is invisible" (medium). It is a **correctness bug**.
`home_feed` publishes a pvi computed at 100 % (`20260723090000_home_feed_photo.sql:51`)
while the engine pays at 95 %. Because that value is **non-null**, every client-side
fallback is bypassed — so a receipt opened from Home inherits the wrong figure, and
where the ~0.6 shift crosses a band boundary, the wrong band name too. `round_card`
already returns the correct `playing_index`; `grep -c playing_index index.html` → **0**.
D174's composer bug one surface over; D178 measured the same class on iOS at 71/289 rounds.
*Re-verified independently.*

### 2 · Building D182 as written would corrupt the handicap index
D182 says `score_round` already falls back to `rating/2`. True of the **7-arg helper**
(`baseline:698`) — which is **not on the posting path**. The trigger that computes
`rounds.differential` is the **0-arg** `score_round()`
(`20260716100000_handicap_engine.sql:69-92`), and it has no such fallback. Relaxing the
guard without deriving *and storing* the nine rating posts a 46-stroke nine as
≈ **−22 differential** — tanking the index and paying max points. The naive fix is
worse than the bug. Scope also grows: `claim_round`
(`20260716140000_wolf_skins_claim.sql:75, 215`) carries the identical guards.
*Re-verified independently.*

### 3 · The review notes point Apple at a screen that no longer renders
`docs/ios/app-review-notes.md:61-64` still describes "a future season pass (paid on the
web by the league's organiser) … on one informational screen". D183 parked pricing with
`visible=false`, so that screen does not render — and volunteering a web-payment story is
exactly the 3.1.1 conversation a free app never needs to open. Not in the audit at all.
*Re-verified independently.*

## Definition of done — nine means all nine

1. **Nothing vanishes.** No path where the app accepts a round, a score or a tap and discards it.
2. **Nothing is dead but silent.** Every failure produces words on screen — including a boot that never ran.
3. **One number.** Every points figure identical on every surface, closing by hand from the receipt.
4. **The floor holds.** AA contrast in all three theme surfaces, focus trapped and restored, selected state announced.
5. **The door sells.** 6 of 8 strangers can say what Cup Season is after 30 seconds on a phone.
6. **The funnel prints.** All six nodes record, then a stated cold-signup conversion rate.
7. **It is in review.** Submitted, reviewer password + seeded league + live AASA all proven.
8. **Real people used it.** A cohort past one device, two weeks, crash-free.
9. **None of it can regress.** Every fix above is an invariant in preflight or CI, not a memory.

## How the work should run

- **One db push, not four.** 0.2, 0.3 and 0.4 each need a migration. Author all three, dry-run each
  in `begin; … rollback;`, then hand off a single `supabase db push`.
- **Resolve the decision-number collision first.** Two streams independently proposed **D186**
  (the allowance sweep, and the door + funnel entry). Assign them before either starts — parallel
  sessions colliding on a shared line is this repo's oldest failure mode.
- **Decisions before code.** Rule 5 binds 0.2 and 0.4. D182 and D131 exist and need **amending,
  not renumbering** — and the D182 amendment is what stops the engine error being built as written.
- **Three machines, one branch each.** Most is remote-safe; the iOS halves of 0.3, the screenshots
  and every Xcode step are Mac-only; db pushes, Apple portals and the legal generator are the user's.
- **Turn each fix into an invariant.** Five new preflight checks fall out of this plan: no
  cross-origin import on the boot path · contrast maths across all three theme surfaces · focus
  traps matching `aria-modal` · segs carrying `aria-pressed` · a banned-word lint.
- **Route each session to its lane** (`spec/session-tracks.md`): Gameplay owns 0.2/0.3; UX owns
  1.1/1.2; Growth & Ops own 0.1/0.4/1.3; Growth & Launch own phase 2.

  After submission, with the smoke test standing.

  only as desktop-only ambient decoration. Record the debt; don't put fiction at the centre of the pitch.
- **Restoring the retired demo peek.** `index.html:17223-17228` says outright not to restore it a
  third time without a decision entry. This is that entry, and it says no.

- **The captains-pick / snake-draft engines.** Unbuilt, and the wizard honestly sells only what
  exists. Not needed for a 9.
