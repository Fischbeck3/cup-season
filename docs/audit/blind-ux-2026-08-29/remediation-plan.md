### The three biggest risks and how the plan handles them

1. **Deploy skew** (Netlify and `db push` are separate; either can land first). Every new RPC defaults its added params; every new client call falls back on the "could not find the function / schema cache" class (never on message sniffing beyond that regex — it is the one `humanError` already knows at `index.html:4113`); `home_feed`'s old one-arg overload is dropped in the same migration that adds the two-arg version (PostgREST cannot choose between two); `lockBylaws` keeps today's sequence as `lockBylawsLegacy()` until A-05 deletes it; the policy drop (A-05) runs only after A-02 is on Netlify AND A-03 is on TestFlight. Each item's row says which order is safe.
2. **RLS / grants (D37).** Every migration in this plan re-issues `revoke all … from public, anon` + `grant execute … to authenticated` (anon only for `join_covenant_info`, which stays the one anon window and never returns the payment note, names to signed-out callers, emails, handles or the allowance); every migration that adds a view revokes it from all API roles and ends in a `do $$ … raise` self-check (the growth_events precedent — a grant claim is worth nothing until something fails on it); `tests/db-checks.sql` 2/3/9/10 run after every push, and the new checks 19/20/21 make the plan's own claims self-enforcing; `tools/build-db.mjs` regenerates `Rpc.swift` after every push so D37 is enforced by the Swift compiler (preflight 11/14/17).
3. **iOS parity drift (D100).** Every web item carries a phone line (§7 cross-walk, column "iOS"); each phase ends with one local iOS wave that ships in the same TestFlight as its web counterparts; the only permanent web-only items are the install nudge (Q-13) and the free-identifier lint (Q-04) — by construction, not by omission; copy lives once (the D122 phrase family, `BANDS`, `STAGE_LABEL`, `GAME_RULES`, `floorSentence`, `endgameLine`, `inviteMessage`) and preflight 23 fails the push when the web and Swift tables differ; preflight 18 fails when the two clients' event vocabularies drift. A handoff that ships web-first must say "web-only until TestFlight build N" in so many words.
