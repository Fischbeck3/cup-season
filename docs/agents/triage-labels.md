# Triage labels

Use these default labels when a skill refers to a triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

These labels describe workflow status and can coexist with category labels such
as `bug` and `enhancement`. During authorized triage, inspect existing labels
and create missing role labels before applying them. Preserve other labels.
